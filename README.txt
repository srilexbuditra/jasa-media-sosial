# Srilex Buditra — Social Media Pricing Website

Website statis responsive dengan:
- Landing page paket & harga
- Paket Starter, Growth, Professional
- Kalkulator estimasi harga
- Pilihan media: Instagram, TikTok, Facebook, YouTube
- Jenis jasa promosi
- Fitur tambahan
- Tombol order WhatsApp
- FAQ, cara order, layanan, footer
- Responsive desktop/tablet/mobile

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka `index.html` di browser.
3. Untuk online hosting, upload `index.html`, `style.css`, dan `script.js` ke hosting/GitHub Pages.

## Yang perlu disesuaikan
- Nomor WhatsApp di `script.js` (saat ini contoh `6282136238350`).
- Email/kontak di `index.html`.
- Harga dan nama layanan di `index.html`.
- Warna, logo, dan identitas brand di `style.css`.

Catatan: kalkulator memberikan estimasi. Harga final sebaiknya dikonfirmasi berdasarkan kebutuhan layanan dan kebijakan platform.
